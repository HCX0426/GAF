```

                                    ↓

                              [ESC → wait_map_indicator] → 地图

                              [ESC → wait_main_menu] → 主界面 ✅
```

### 3.2 get_email（领取邮箱）

```
主界面 → [click 邮箱图标] → 邮箱列表
                              ↓
                    [wait_regular_email] OCR "普通邮箱"
                              ↓
                    [detect_empty_email] 空邮箱检测
                              ↓
                    [branch] ── 空 → back_to_main → 主界面 ✅
                    [branch] ── 非空 ↓
                              [click "全部领取"]
                              ↓
                    [wait_mailbox_still_visible]
                              ↓
                    [click_back_dismiss_popup]
                              ↓
                    [call_back_to_main] → 主界面 ✅
```

| 界面 | 触发方式 | 验证模板/文本 | ROI |
|------|----------|--------------|-----|
| 主界面 | 初始 | 主界面.png | [1720, 20, 120, 70] |
| 邮箱列表 | 点击邮箱图标 | OCR "普通邮箱" | [214, 10, 333, 276] |

### 3.4 get_pvp（PVP 竞技场）

```
主界面 → [direct_hit 1720,990] → 游戏卡带界面
                                     ↓
                            [wait_game_collection]
                                     ↓
                            [click PVP地图] → 选择地图界面
                                     ↓
                            [wait_arena_identifier] → 竞技场界面
                                     ↓
                            [click_enter_arena] → 战斗界面
                                     ↓
                            [wait_auto_battle] → 自动战斗可见
                                     ↓
                            [click_auto_battle]
                                     ↓
                            [wait_multiplier_visible] × 15 场
                                     ↓
                            ... (循环 15 场) ...
                                     ↓
                            [wait_battle_complete] → 战斗结果
                                     ↓
                            [click_close_result]
                                     ↓
                            [click_leave_battle] → 离开确认
                                     ↓
                            [click_confirm]
                                     ↓
                            [press_h] → 地图 → [ESC] → 主界面 ✅
```

**关键界面转换**:
1. 主界面 → 游戏选择界面（direct_hit 点击坐标）
2. 游戏选择界面 → 选择地图界面（点击 pvp地图.png）
3. 选择地图界面 → 竞技场界面（direct_hit 点击 enter_arena 坐标）
4. 竞技场界面 → 战斗界面（OCR "自动战斗" + 点击）
5. 战斗界面 → 战斗结果（等待 X.png 出现）
6. 战斗结果 → 确认离开 → 地图 → 主界面

## 4. 公共子流程

### 4.1 back_to_main.json（返回主界面）

> 被以下任务调用：get_email（空邮箱/领取后）、get_guild、intensive_decomposition（分解后/精炼后）等

```
任意子界面 → [click_back_btn] → [wait_main_menu]
                                    ↓ (超时)
                              [ESC] → [wait_main_menu_after_esc]
                                    ↓
                              主界面 ✅
```

| 步骤 | 节点 | 类型 | ROI | 模板 |
|------|------|------|-----|------|
| 1 | click_back_btn | template_match | [120, 20, 100, 66] | 返回键1.png |
| 2 | wait_main_menu | wait (template) | [1720, 20, 120, 70] | 主界面.png |
| 3 | press_esc_fallback | key_press | — | ESC 键 |
| 4 | wait_main_menu_after_esc | wait (template) | [1720, 20, 120, 70] | 主界面.png |

**注意**: `wait_main_menu` 有 `continue_on_error: true`，即使失败也会继续执行 ESC 降级。

### 4.2 dismiss_popup.json（关闭弹窗）

```
任意界面（有弹窗）→ [click 返回键] → [wait 2s] → 弹窗关闭 ✅
```

| 步骤 | 节点 | 类型 | ROI | 模板 |
|------|------|------|-----|------|
| 1 | click_back_dismiss | template_match | [120, 20, 100, 66] | 返回键1.png |
| 2 | wait_dismiss | wait (fixed) | — | 2.0 秒 |

## 5. 界面状态机（简化）

```
                    ┌──────────────────────────────────────┐
                    │                                      │
    ┌──────────┐    │    ┌──────────┐    ┌──────────┐     │
    │ 主界面   │────┼───→│ 子界面 A │────→│ 子界面 B │     │
    │ (初始)   │    │    │ (如邮箱) │    │ (如领取) │     │
    └──────────┘    │    └──────────┘    └──────────┘     │
         ↑          │         │              │            │
         │          │         │              │            │
         │          │         │    ┌─────────┘            │
         │          │         │    │                      │
         │          │    ┌────▼─────┐                    │
         └──────────┼────│ 弹窗层   │                    │
      (back_to_main)│    │ (dismiss) │                    │
                    │    └──────────┘                    │
                    │                                      │
                    └──────────────────────────────────────┘
```

**关键状态转换**:
- 主界面 → 子界面：通过点击对应图标/按钮触发
- 子界面 → 主界面：通过 back_to_main 子流程（返回键 + 主界面验证）
- 任意界面 → 弹窗层：意外弹窗遮挡
- 弹窗层 → 正常界面：通过 dismiss_popup 子流程

## 6. 常见问题 FAQ

### Q1: 任务卡在 OCR 超时（如 wait_regular_email 15s 超时）
**检查**: 截全图看界面是否已切换到目标页面
**常见原因**: 点击节点成功但游戏界面未切换（弹窗遮挡、游戏延迟）
**解决**: 在点击和等待之间添加界面验证节点

### Q2: 模板匹配置信度低（如 0.45 < 0.7）
**检查**: 对比 PrintWindow vs GDI 截图方法的置信度
**常见原因**: 截图方法不匹配当前场景
**解决**: 切换截图方法（BD2 推荐 PrintWindow）

### Q3: back_to_main 子流程失败
**检查**: 是否在正确的界面调用了子流程
**常见原因**: coord_transformer 未从父流程传递
**解决**: 检查 sub_pipeline.py 中 `getattr(context, "coord_transformer")` 是否正确获取

### Q4: 任务执行后画面没变化
**检查**: 上一节点是否真的点击成功
**常见原因**: 弹窗拦截了点击事件
**解决**: 在点击节点后添加 dismiss_popup 节点

### Q5: 如何判断任务是否成功？
**检查**: 对比任务的「出口界面」验证模板
**标准**: 所有任务执行完毕后应回到主界面（主界面.png 可见）
**调试**: 如果最后一个验证节点失败，说明任务未完全执行
