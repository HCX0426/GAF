# BrownDust II ROI 与模板组映射

> **用途**: 记录相同 ROI 坐标的模板组关系。模板匹配失败时，可通过此表快速找到同 ROI 的替代模板进行降级匹配。
> **核心发现**: 相同 ROI 坐标的模板通常对应界面上的**同一个组件**（如按钮的不同状态：默认/高亮/禁用/激活）。

## 2. 使用场景

### 场景 1：模板匹配失败降级

```
问题: open_mailbox 节点使用"邮箱.png"匹配失败 (confidence=0.45 < 0.7)
步骤:
  1. 从映射表找到 ROI [1564, 28, 95, 61]
  2. 获取同 ROI 的模板组: [邮箱.png, 邮箱_new.png, 邮箱_old.png]
  3. 按优先级排序: [邮箱_new.png, 邮箱_old.png, 邮箱.png]
  4. 依次尝试匹配
  5. 记录结果
```

### 场景 2：OCR 全乱码降级

```
问题: wait_regular_email OCR 11 次全部乱码
步骤:
  1. 检查截图是否被遮挡
  2. 查找当前 ROI 附近是否有弹窗模板
  3. 用公共弹窗模板（返回键1.png）在全图范围内匹配
  4. 如果检测到弹窗 → 执行 dismiss 流程
  5. 重新验证 OCR
```

### 场景 3：界面状态不确定

```
问题: 不确定当前是"普通邮箱"还是"VIP邮箱"
步骤:
  1. 读取当前 ROI 的模板组
  2. 对同 ROI 的所有模板分别匹配
  3. 选择置信度最高的模板
  4. 记录并使用
```

## 3. 降级匹配流程

```python
def template_fallback_match(screen, roi, primary_template_path):
    """
    同 ROI 模板降级匹配
    
    Args:
        screen: 当前截图 (numpy array)
        roi: ROI 坐标 [x, y, w, h] (base resolution)
        primary_template_path: 主模板路径
    
    Returns:
        匹配结果 (success, template_path, confidence)
    """
    # Step 1: 从本映射表获取同 ROI 的模板组
    template_group = get_templates_for_roi(roi)
    
    # Step 2: 主模板优先，其他模板按名称相似度排序
    sorted_templates = prioritize(primary_template_path, template_group)
    
    # Step 3: 依次尝试匹配
    for template_path in sorted_templates:
        result = template_match(screen, template_path, roi=roi, threshold=0.7)
        if result.success:
            return {
                'success': True,
                'template': template_path,
                'confidence': result.confidence,
                'is_fallback': template_path != primary_template_path
            }
    
    # Step 4: 全部失败
    return {'success': False, 'templates_tried': len(sorted_templates)}
```

## 4. 维护说明

### 新增模板时

1. 确定模板所属的 ROI 坐标
2. 查找映射表中是否已有该 ROI 的条目
3. 如果有 → 追加到模板组
4. 如果没有 → 新增 ROI 条目

### 修改 ROI 时

1. 同步更新映射表中的坐标
2. 检查是否影响同 ROI 的其他模板

### 废弃模板时

1. 从模板组中移除
2. 在备注栏标记废弃日期和原因
