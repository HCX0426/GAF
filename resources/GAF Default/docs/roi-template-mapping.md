## 3. 降级匹配

由于 GAF Default 是示例资源包，模板数量较少（通常每个 ROI 只有一个模板）。降级匹配主要用于：

- 不同状态的同一组件（如激活/禁用）
- 不同版本的同一模板（如更新前后的图标）

如需添加同 ROI 的模板，参考 BrownDust II 的映射表格式。
