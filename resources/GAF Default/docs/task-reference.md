## 4. 已知问题

### ⚠️ ROI 坐标超出基准分辨率

GAF Default 资源包的基准分辨率是 1280×720，但部分 ROI 使用了 BD2（1920×1080）的坐标值：

| ROI | 当前值 | 基准分辨率 | 问题 |
|-----|--------|----------|------|
| [1720, 20, 120, 70] | 超出 | 1280×720 | x=1720 > 宽度 1280 |
| [1740, 20, 175, 88] | 超出 | 1280×720 | x=1740 > 宽度 1280 |
| [1600, 833, 170, 140] | 超出 | 1280×720 | x=1600 > 宽度 1280 |

**建议**: 将这些 ROI 按比例缩放到 1280×720 基准，或使用相对坐标系统。

## 5. 常见问题 FAQ

### Q1: 模板匹配始终失败？
**检查**: ROI 坐标是否超出屏幕边界
**可能**: GAF Default 使用 BD2 的 ROI 坐标，但基准分辨率不同

### Q2: 任务如何调试？
**步骤**:
1. 截取全屏截图 (full_screen ROI)
2. 检查模板在截图中的位置
3. 调整 ROI 坐标到正确位置
4. 重新测试
