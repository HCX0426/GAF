# POST /api/v2/tasks 返回 404

## 症状

前端 `axios.post('/api/v2/tasks', data)` 返回 404，但 GET 同路径正常。

## 触发条件

- DRF（Django REST Framework）ViewSet 路由
- 前端 axios 拦截器未自动加尾随斜杠
- DRF `APPEND_SLASH = True` 默认开启

## 根因

DRF `APPEND_SLASH=True` 要求 POST/PUT/DELETE 请求必须带尾随斜杠 `/`，但浏览器/axios 不会自动加。

## 解决步骤

1. 前端 `axios.create({ baseURL: '/api/v2' })` 拦截器自动补 `/`
2. 或后端关闭 `APPEND_SLASH`，明确要求前端路径
3. 推荐方案：前端补 `/`

## 验证

- `curl -X POST http://localhost:8000/api/v2/tasks/` 返回 201/400 而非 404
- 前端 Network 面板 URL 含尾随斜杠

## 预防

- 前后端约定：所有 mutation 请求必须带 `/`
- 加 ESLint 规则禁止裸 mutation 路径
